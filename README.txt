AI Newsroom SmartDesk 2.0.10

Changes in 2.0.10:
- Rolled back to the 2.0.6-style writing pipeline before Wire Editor was added.
- Removed the separate Quality Gate AI step.
- Removed Quality Gate model/global toggle/campaign toggle from the admin UI.
- Article generation now uses: Story Desk → Research Pack → Article Writer → Publish/Draft.
- Writer quality_score/quality_notes are still stored for review, but no extra AI gate blocks the article.
- Keeps the 2.0.6 admin UI improvements, source expansion UI, spinner-only buttons, smart grouping/source card pipeline, and OpenRouter image integration.
